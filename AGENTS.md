# Cloud Agents

This repository is a static GitHub Pages site. There is no build step, no Netlify, and no secrets.

Publishing is a push to `main`. The custom domain is `mirrorsmusic.co.il`; keep `CNAME` exactly as that hostname.

Local preview while working in a Cloud Agent: [http://127.0.0.1:8080](http://127.0.0.1:8080) (started via `.cursor/environment.json`).
